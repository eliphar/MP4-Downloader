# 📥 MP4-Downloader

A modern, high-speed, and user-friendly social media video downloader built with Python. This application allows users to download videos from various platforms like YouTube, Instagram, TikTok, and X (Twitter) with a sleek graphical user interface.



## ✨ Features
- **Multi-Platform Support:** Seamlessly download videos from YouTube, Instagram, TikTok, X (Twitter), and more, powered by the robust `yt-dlp` engine.
- **Modern UI:** Built with `CustomTkinter`, offering a clean, dark-themed professional look.
- **Custom Download Location:** Choose exactly where you want to save your videos using an intuitive folder picker.
- **Real-time Progress Tracking:** Monitor your download percentage and status with a visual progress bar.
- **Asynchronous Downloading:** Uses threading to ensure the UI remains responsive and doesn't freeze during downloads.

## 🛠️ Technology Stack
- **Language:** Python 3.x
- **GUI Framework:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)
- **Downloader Engine:** [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- **Image Processing:** [Pillow](https://python-pillow.org/) (PIL)

## 📖 How to Use

1. **Copy the URL** of the video you wish to download from your browser or app.
2. **Paste the link** into the input field in the application.
3. **Select a destination folder** by clicking the "Select Folder" button.
4. **Click "Start Download"** and watch the progress bar.
5. Once finished, your video will be ready in the selected directory!
